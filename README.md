# 1SubTV Remote

Customer-friendly Android remote for onn./Android TV/Google TV devices.

## Product goals
- Open app → automatically find TV → tap TV → enter the pairing code shown on TV → done.
- No IP addresses, ADB setup, developer options, or customer accounts.
- D-pad/OK, Back, Home, volume/mute, playback and phone keyboard input.
- Save pairing credentials and reconnect automatically.
- Dark-blue 1SubTV branding.
- Small unobtrusive promotional area that never covers remote controls; no pop-ups, full-screen ads, or countdowns.
- Promotion content is designed to be remotely configurable (image, headline, text, button/URL, enabled state and schedule).

## Status
Initial Android project scaffold committed. Remote v2 discovery/pairing transport and remote promotion configuration are the next implementation steps.
